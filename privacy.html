Privacy Policy

Last updated: 6 November 2026

Ser El Brand Studio (“the app”) is a private tool operated by the owner of the YouTube channel “سر البراند” (channel link). It is used only by that owner, on the owner's own computer.

Google user data the app accesses

When the owner signs in with Google, the app requests these permissions:

  • youtube.upload — to upload videos to the owner's channel;
  • youtube.force-ssl — to set video thumbnails and upload captions on the owner's channel;
  • yt-analytics.readonly — to read performance statistics of the owner's own videos.

How the data is used

The data is used only to provide these features to the channel owner: uploading the owner's videos, adding their thumbnails and captions, and showing the owner how those videos perform. The app does not use Google user data for advertising, does not sell it, and does not transfer it to anyone.

Storage and security

OAuth tokens and analytics are stored only on the owner's computer, in a file readable only by the owner's user account. Nothing is stored on any server operated by the app.

Sharing

Google user data is not shared with any third party. Video files and their metadata are sent only to YouTube, at the owner's direction.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also complies with the YouTube API Services Terms of Service; by using it you agree to the YouTube Terms of Service, and Google's processing is described in the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local data folder removes all stored tokens and analytics.
